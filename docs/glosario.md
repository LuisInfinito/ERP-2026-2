# Glosario del flujo

[Índice](../README.md)

| Término | Significado |
|---|---|
| Sprint | Semana de trabajo con un área y un objetivo acordado |
| Núcleo | Recorrido mínimo comprometido para esa semana |
| API | Entrada del sistema que recibe peticiones de las pantallas |
| PR | Propuesta de cambios revisada por otra persona antes de integrarse |
| CI | Comprobaciones automáticas de compilación y pruebas |
| WIP | Cantidad de trabajo abierto al mismo tiempo |
| Contrato | Acuerdo sobre entradas, resultados y errores entre módulos |
| Adaptador simulado | Implementación sencilla que imita un servicio aún no disponible |
| Historial | Registro inmutable de quién cambió qué, cuándo y por qué |
| Cadena documental | Relaciones entre un documento, su origen y sus derivados |
| Migración | Cambio versionado de la estructura de la base de datos |
| SDK | Herramientas para compilar y ejecutar el proyecto |
| CRM | Gestión de clientes y oportunidades comerciales |
| OV | Orden de venta |
| TO-BE | Descripción del proceso de negocio propuesto |
| EF Core | Herramienta de acceso a datos para .NET |
